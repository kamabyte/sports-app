# Sports

Спортивный раздел поверх домашнего IPTV: вместо тысяч каналов — события
(матчи, гонки, турниры). Нашёл событие → открыл канал, где его показывают.
Как спорт в Apple TV или Кинопоиске.

События — матчи из расписания (API лиг), к которым привязаны показы на
каналах домашнего Dispatcharr (Xtream Codes). Телегиды — свои: XMLTV из
открытых источников, каналы привязываются к ним сами. Поток канала играет
прямо в браузере (mpegts.js). Для разработки и тестов есть фейковый каталог
(`SPORTS_SOURCE=fake`).

Laravel 13 + Inertia 3 + React 19 + TypeScript, Tailwind 4, shadcn/ui,
Fortify (вход, 2FA, passkeys), Sanctum (токены ТВ-клиентов), SQLite.

Документация на английском: [архитектура](docs/architecture.md),
[API для ТВ-клиентов](docs/api.md), [эксплуатация](docs/operations.md).

## Запуск

```bash
composer setup              # зависимости, .env, ключ, миграции, сборка
php artisan db:seed         # demo@sports.test / password — только для разработки
php artisan storage:link    # эмблемы отдаются из storage/app/public
php artisan guide:import    # каналы Dispatcharr (DISPATCHARR_* в .env) и телегиды
php artisan fixtures:import # расписание матчей (команды, эмблемы, счёт)
php artisan logos:sync      # эмблемы — к нам
composer dev                # сервер, очередь, логи, планировщик и Vite
```

Регистрации нет. Учётная запись (или новый пароль существующей):

```bash
php artisan sports:user you@example.com --name="Имя"   # пароль спросит или сгенерирует
```

Проверки: `php artisan test`, `vendor/bin/phpstan analyse`, `vendor/bin/pint --test`,
`npm run check`, `npm run types:check`, `npm run build`.

## Как собираются события

**Расписание — источник событий, телегид только добавляет к ним показы.**

```
API (КХЛ, ESPN, Евролига, LiveScore, TheSportsDB) → fixtures → MatchBuilder → матчи (sport_events)
Dispatcharr (каналы) + телегиды XMLTV → ChannelMatcher → TitleParser → AiringMatcher → показы матчей (airings)
Событие в интерфейсе = матч из расписания, у которого есть показ на ваших каналах.
```

1. `fixtures:import` (раз в час) загружает матчи всех источников (`FixtureSource`) в
   `fixtures`, `Guide\Matches\MatchBuilder` собирает из них матчи: один матч у
   нескольких источников — одно событие (тот же вид спорта, начало ±15 минут, те же
   команды; `fixtures.sport_event_id`). Основной источник — лучший (КХЛ > Евролига >
   ESPN > TheSportsDB > LiveScore): его время, команды, турнир, счёт и статус. id матча
   не меняется между загрузками; матч, пропавший из всех источников, удаляется.
2. `guide:import` (каждые 30 минут) загружает каналы Dispatcharr и телегиды (см.
   «Телегиды»), разбирает передачи (`Listings\TitleParser`: вид спорта, турнир,
   соперники; обзоры и студии отбрасываются) и `Guide\Matches\AiringMatcher`
   привязывает их к матчам:
    - с соперниками — по похожести обеих команд (`Matches\TeamMatch`,
      `Fixtures\NameSimilarity`: латиница, звучание, страны, сокращения; короткие
      названия — только точно, «СКА» ≠ «ЦСКА») и времени: во время матча — прямой эфир,
      после (до двух недель) — повтор;
    - без соперников («Чемпионат КХЛ») — матч того же турнира, начинающийся в эти минуты,
      если он такой один.
      Передача, не нашедшая матча, не показывается: телегид событий не создаёт. Русские
      названия из телегида становятся названием матча и написаниями команд.

Фильтра по турнирам пока нет: показывается любой матч из расписания с показом на
ваших каналах. Курируемый список турниров (`CompetitionCatalog`) — только для имён,
эмблем и веса. Виды спорта без расписания (теннис, Ф-1, единоборства) появятся с
новыми источниками.

## Телегиды

Телегид Dispatcharr не используется: от Dispatcharr нужны только каналы, их
tvg-id (плейлист `/output/m3u?tvg_id_source=tvg_id`, без логина) и потоки.

- **Источники** — `sports.guides.sources`: EPG One (русские каналы), файлы
  epgshare01 по странам (Plex, США, Великобритания, Чехия, Словакия, Венгрия,
  Италия, Франция, Румыния, Сербия, Колумбия, Мексика, Индия), Samsung TV Plus
  и Roku (i.mjh.nz). Файлы скачиваются раз в `GUIDES_REFRESH_HOURS` (12 ч) в
  `storage/app/private/guides` и читаются потоком (`Listings\XmltvReader`: EPG
  One — 700 тысяч передач за ~3 с). Не скачался — берётся прежний файл,
  `guide:import` предупреждает; не загрузился ни один — ошибка, данные не трогаются.
- **Привязка каналов** (`Listings\ChannelMatcher`, при каждой загрузке): по tvg-id
  («Sport1.cz@SD» → «Sport1.cz», «2003» у EPG One), иначе по названию без пробелов,
  качества и страны в конце («Teledeporte HD ES» = «Teledeporte»), только в той же
  стране: страна — из tvg-id и из id или названия канала в телегиде («SPORT 4 HD
  IL»). По названию берётся только канал с настоящей программой (не одна
  передача весь день). tvg-id, равный номеру канала, — подстановка Dispatcharr, а
  не id. Версия канала («FIFAPlus.uk@Spain») по общему названию не ищется. Что
  нашлось — в `channels.guide_source` / `guide_channel`.
- **Вручную** — `sports.guides.channels`: `'Название канала' => 'источник:id'` или
  `null` (без телегида).
- **Языки**: виды спорта, стадии, «прямой эфир / повтор» и женские команды — по-русски,
  по-английски, по-чешски, по-словацки, по-венгерски, по-румынски, по-сербски,
  по-испански, по-французски, по-итальянски; пары через «–», «vs», «v», «at»
  (хозяева — вторые) и «/»; страны — на всех этих языках (ICU). Если в
  названии только вид спорта («Lední hokej», «WNBA Basketball»), соперники
  ищутся в подзаголовке и коротком описании.

## Источники расписания

`sports.fixtures.sources`, у каждого `*_ENABLED`; сбой одного не мешает остальным,
`fixtures:import` падает, только если не загрузилось ничего. Неделя вперёд
(`FIXTURES_DAYS_AHEAD`), TheSportsDB — два дня (`THESPORTSDB_DAYS_AHEAD`).

| Источник            | Что                                                  | Заметки                                                                                                  |
| ------------------- | ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| `KhlSource`         | КХЛ                                                  | мобильный API, названия по-русски, эмблемы                                                               |
| `EspnSource`        | футбол (РПЛ, топ-5, еврокубки, Лига наций), НХЛ, НБА | неофициальный, без ключа; запрос на лигу в день; эмблемы лиг                                             |
| `EuroleagueSource`  | Евролига, Еврокубок                                  | API сайта, сезон одним запросом                                                                          |
| `LiveScoreSource`   | сотни лиг футбола, хоккея, баскетбола, живой счёт    | неофициальный, условия сайта такое не разрешают — для личного использования; id — `вид:Eid`              |
| `TheSportsDbSource` | волейбол, гандбол, регби                             | бесплатный ключ `123` — 3 матча на вид спорта в день и ~3 запроса в минуту (`THESPORTSDB_PAUSE_SECONDS`) |

Championat и Flashscore не используются: оба закрыты от программ (вход через SberID
с JS-проверкой, подписанные запросы), обходить это не будем.

## Команды, турниры, эмблемы

- **Команды** (`teams`, `team_aliases`, `Guide\Teams\TeamRegistry`) — одна на
  все написания. Источники расписания заводят команды и приносят эмблемы
  (лучшая побеждает: КХЛ > Евролига > ESPN > TheSportsDB > LiveScore). Привязав
  передачу к матчу при полном совпадении обеих команд, `AiringMatcher` запоминает
  русские названия из телегида как написания команд. Показывается русское
  название из телегида, эмблема — команды.
- **Сборные** (`Guide\Teams\NationalTeams`) — страна по названию на русском
  или английском (ICU + расхождения вроде Türkiye/Turkey, сборные Англии,
  Шотландии, Уэльса и Северной Ирландии), с категорией (U21, женщины).
  Сборная — только если страны с обеих сторон («Монако — Тулуза» — клубы).
  Одна команда на страну и категорию из всех источников и телегида; эмблема —
  флаг flagcdn.com (рисуется круглым на весь значок), расписание для этого не нужно.
- **Турниры** (`competitions`, `Guide\Competitions\CompetitionCatalog`) —
  курируемый список (~35): имя, короткое имя, страна, вес и шаблоны названий
  на русском и английском («КХЛ», «Чемпионат КХЛ», «Russian KHL» → КХЛ;
  «CONCACAF Nations League» — не Лига наций). Эмблемы — от ESPN (лиги, которые
  он отдаёт) и бейджи TheSportsDB, заданные в каталоге. Остальные турниры —
  текстом из телегида, вес — `CompetitionRank`.
- **Эмблемы у нас** — `logos:sync` (ежечасно, после расписания; сначала то, что
  есть в событиях телегида, — команд из расписания тысячи) скачивает их, вписывает в 256×256 и сохраняет в WebP (`storage/app/public/logos`,
  нужен `php artisan storage:link`). Отдаются от корня сайта (`/storage/…`),
  с чужих CDN ничего не грузится. Не скачалось — повтор через сутки.

## Устройство

- **Каталог событий** — `App\Guide\EventCatalog`: виды спорта, турниры,
  события, поиск события по id. Привязан в `AppServiceProvider`; там же
  route binding `{event}` (событие — не модель). Реализации две:
  `DatabaseEventCatalog` (матчи расписания с показами в телегиде, по умолчанию) и
  `FakeEventCatalog`: неделя вокруг сегодняшнего дня по сетке из
  `Fake\Fixtures` (время — UTC, сетка плотная, чтобы в эфире всегда что-то
  было). Генерация детерминирована (сид — турнир + дата), id вида
  `epl-20261006-2` всегда разворачивается в то же событие.
- **Событие** (`Guide\Data\Event`) — соперники, турнир, стадия, время начала
  матча, счёт из расписания, трансляции (`Broadcast`: канал, логотип, номер, язык,
  источник, запись EPG, время показа, прямой эфир или повтор). Статус и прогресс
  считаются от начала матча; фронт пересчитывает статус по часам браузера.
- **Главная** — `Guide\HomeShelves` (общая для веба и API): витрина, «Сейчас
  в эфире», «Скоро начнётся», полка на каждый вид спорта.
- Часовой пояс расписания — `SPORTS_TIMEZONE` (по умолчанию Europe/Moscow):
  по нему день делится на сутки, им же фронт форматирует время.
- Трансляции события сортируются по `sports.preferred_languages`, внутри
  языка — по качеству.

### Веб (`routes/web.php`, всё за входом)

`/` главная, `/schedule?date=&sport=` программа на день, `/sports/{sport}?competition=`,
`/channels` (все каналы по категориям, что идёт сейчас), `/channels/{channel}` (эфир
канала и его матчи), `/events/{event}`, `/events/{event}/watch/{broadcast?}` (поток канала, mpegts.js),
`/events/{event}/watch/{broadcast}/playlist.m3u`, `/search?q=`, `/settings/*` (профиль, 2FA, passkeys, тема).

### API для ТВ-клиентов (`routes/api.php`, префикс `/api`, имена `api.*`)

- `POST /api/tokens` `{email, password, device_name}` → `{token, user}`;
  дальше `Authorization: Bearer <token>`. `DELETE /api/tokens/current` — выйти.
- `GET /api/home` → `featured`, `live`, `starting_soon`, `sports[{sport, events}]`.
- `GET /api/sports` → виды спорта с турнирами.
- `GET /api/events?sport=&competition=&status=live,upcoming&date=Y-m-d&q=` (`q` > 100 символов → 422).
- `GET /api/events/{id}` — событие с трансляциями.
- `GET /api/channels` — все каналы с матчем, который идёт сейчас; `GET /api/channels/{id}` —
  канал, его поток и матчи (сейчас и впереди).
- `GET /api/events/{id}/broadcasts/{n}/stream` → `{broadcast, stream: {type: "mpegts", url}}`
  (`type: "demo", url: null` у фейкового каталога). У трансляций есть `starts_at`/`ends_at`,
  `live` (показ во время матча) и `replay` (после).

Ошибки под `/api/*` — всегда JSON.

## Стиль кода

Как в mytube: один контроллер на ресурс; API-контроллеры — в
`App\Http\Controllers`, веб — в `App\Http\Controllers\Web`; ресурсы для
Inertia передаются через `->resolve()`; валидация двух и больше полей — в
FormRequest с типизированными аксессорами; плоские `return` /
`Inertia::render()`; типизированные константы и типы возврата везде;
сервисы возвращают небольшие readonly-объекты. Перед коммитом —
`vendor/bin/pint --dirty`.
